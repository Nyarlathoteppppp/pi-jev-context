# Model performance first. Token savings second.

- When in doubt, keep full output. Fold only exact duplicates at the same path and file positions in current, compaction-aware context.
- Protect the cache prefix: transform only arriving results; never rewrite old messages or change tool declarations on mode switches. Do not trigger compaction to save tokens.
- Disable folding with a reproducible, attributable capability regression. Recall does not prove losslessness; do not promise zero risk or guaranteed cache hits.
- Keep old-context pruning and third-party compaction outside the runtime. The v0.5 fresh-output sieve is independently configured, uses hard KEEP rules, and fails open.
- Freeze acceptance criteria before live runs. Report failures and limitations honestly. Publish aggregates, never private session content or credentials.
- Write repository documentation and commit messages in English.
